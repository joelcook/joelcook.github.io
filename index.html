bio

Joel Cook is an AI architect at Indian River State College, a public college in Florida, building the college’s AI advisor, migration tooling, and internal software in-house instead of buying them. The work centers on AI that handles private data carefully: answers grounded in official sources, read-only access to systems of record, and personal information kept out of the models. Earlier roles include patient-facing healthcare apps at Modea, live sports software at FloSports, and launch sites for Stellantis brands.

projects

RiverGuide answers students’ questions from the college’s own website. It searches about 2,400 official pages, links every answer to its source, and catches names, addresses, and ID numbers in the browser before anything is sent. It runs on a local model on our own GPU, and a 53-question test set gates every change. Version two is modeled on how America.gov works; version one ran on Copilot Studio.

The Workday-to-Banner classifier migrated 1 million undocumented or mislabeled files into Banner, saving the college over $600,000 compared with an outside consultant’s quote. Names and IDs are masked before matching, uncertain files go to an approved fallback instead of a guess, and an optional local model only ever sees redacted input.

The Banner MCP server lets staff ask the college’s ERP questions in plain English. A local model writes the GraphQL, and a gate checks it against an allowlist before it runs: read-only, no student records, and the model never holds the API key. It also works as a connector in Claude.

RiverBoard is our team’s task board, built with no dependencies: Python’s standard library, SQLite, and plain JavaScript. Teammates connect Claude to it over MCP, and every project carries an estimated-savings figure.
