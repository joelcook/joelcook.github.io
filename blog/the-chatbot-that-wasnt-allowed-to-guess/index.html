The college’s student assistant answers in students’ own words, looks up every fact that changes, and is graded on 53 test cases.

The problem

The old chatbot answered only when students used its exact wording.

What changed

  • Explanations live in a wiki, each linked to its source (the idea from Andrej Karpathy’s LLM wiki).
  • Facts that change, like tuition and drop deadlines, live in a database, and the assistant looks them up every time.
  • 12 read-only tools, served from Azure Container Apps and connected to Copilot Studio.
  • Refreshing sources, rewriting explanations, and deploying are separate steps.

How it’s tested

  • 53 cases: answers, required lookups, conflicting sources, and refusals.
  • A right answer that skipped the required lookup still fails.
  • An AI judge grades explanations only after the exact checks pass.

Read the failures

One Copilot Studio review marked correct privacy refusals as incomplete. The assistant had refused to share private student information, as it should. A score isn’t the story until you read the misses.

The limit

No assistant can promise it never makes something up. This one gets better sources, tested behavior, and failures traced to evidence.
