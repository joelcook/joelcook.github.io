What changed

  • Version one keeps a wiki copy of the college’s site. Every page change had to be copied.
  • RiverGuide 2 searches the college’s own pages. If a page is wrong, it’s fixed on irsc.edu and the next crawl picks it up.
  • Keyword search (BM25), the same kind America.gov uses. No vector database.
  • Every answer links the page it came from.

Privacy

  • Rampart Edge, from the National Design Studio, blocks names, street addresses, and ID numbers in the student’s browser.
  • A link reaches the student only if it’s a real college page.
  • No conversation is kept, and the logs don’t keep what students type.

The first live score

Test questions passed, of 54

  • Cloudflare’s free plan stops a Worker after 10 ms of CPU. Checking an answer takes up to 2 seconds, so answers were thrown away.
  • The $5 plan allows 30 seconds: 41 of 54.
  • 8 answers were still blank: the deployed Worker kept the old limit. Setting it to 30 seconds and redeploying fixed them.
