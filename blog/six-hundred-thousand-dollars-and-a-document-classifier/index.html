Where the records went

Document records

64% got a specific type. The rest went to an approved Legacy folder instead of a guess.

The job

  • More than half a million files: financial aid forms, admissions paperwork, invoices, W-9s, expense reports.
  • Each record had to land in the right folder, under the right document type, attached to the right person.
  • One outside company quoted $600,000 for the sorting alone. We built it instead.

How it works

  • Python rules match approved phrases to approved destinations.
  • Every document type comes from a sheet signed off by the people who own those records.
  • Known names and IDs are masked before matching. “DE” can mean Dual Enrollment, or be the start of someone’s name.
  • An optional model path uses redacted input only, and a person approves every suggestion. The rules didn’t need it.

Banner’s rules

  • No apostrophes in first or last names.
  • Filenames under 100 characters, so we capped them at 99.
  • HEIC photos converted to JPG.
  • Nearly a million rows split into 38 files of at most 25,000 rows each.

The one that bounced

Two of the 38 files came back. 3,322 records used Workday’s form code for a book authorization (SF_FinAid_Authorization) instead of the words. The other 96,510 book authorizations said it in plain English. One new rule, two files patched, back in the queue.

Checked before it shipped

  • 946,092 lines, counting the header.
  • Zero unknown document types, and zero changes anywhere changes weren’t allowed.
  • 694,173 Banner IDs carried through intact.
  • Every reviewer change has a stable record hash and an audit trail.
